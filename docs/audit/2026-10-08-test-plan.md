# Test plan, 2026-10-08

Superseded in part (2026-10-08): the founder kept only simulations as tests (`bun run sim`; docs/CLEANUP-REPORT.md, PRD 34). The unit, golden and e2e tests below were not built or were deleted; the findings they cover are tracked in docs/mvp-gaps.md (critical path item 12b). SITE-10 and Tier 3 are also stale: all four sites are on Cloudflare Pages (docs/deploy.md).

This plan lists every test needed to verify the fixes in [2026-10-08-weaknesses.md](2026-10-08-weaknesses.md). Each test names the finding ids it covers. The priority of a test is the highest severity it covers.

Follow CONTRIBUTING.md 3.4. Each test must run the real code path. Do not test mocks. When you fix a bug, the test must fail before the fix and pass after it.

## Kinds

- **unit**: one function or module, real code, no I/O.
- **property**: generated inputs, an invariant that must always hold.
- **integration**: several modules, real Postgres where named (dev PG on :54339).
- **scenario/sim**: a simulated world or a scenario with pass^k.
- **e2e**: a browser or HTTP client against a running site and API.
- **golden**: a checked-in corpus or snapshot. Corpora of evasions and misreads are append-only.
- **load**: a time or size budget.
